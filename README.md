## 🚀 Live Demo & Quick Start

You can run this project locally without any external dependencies or build tools:

### Option 1: Direct Browser Launch
Simply double-click or open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Node.js)
```bash
# Start the included lightweight server
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 3: Python Built-in Server
```bash
python -m http.server 3000
```

## 🛠️ Technology Stack & Standards

- **Markup**: Pure Semantic HTML5 (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **Styling**: Modern CSS3 using CSS Custom Properties (Variables), Flexbox, CSS Grid, 3D Transforms (`rotateX`, `rotateY`, `perspective`), Backdrop Filters, Keyframe Animations, and Fluid Typography (`clamp()`).
- **Scripting**: Vanilla JavaScript (ES6+) with zero third-party framework dependencies:
  - HTML5 2D Canvas for the interactive particle network.
  - `IntersectionObserver` API for smooth scroll-triggered counter animations and element reveal transitions.
  - Custom Event Listeners for 3D card tilt, modal state management, tab switching, and form validation.
- **Typography**: Google Fonts (*Space Grotesk*, *Plus Jakarta Sans*, *Orbitron*, and *JetBrains Mono*).
- **Icons**: Font Awesome 6.

## 🌐 Deploying to GitHub Pages

1. Initialize git and commit your files:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: NEXORA AI enterprise website"
   ```
2. Create a repository on GitHub (e.g. `nexora-ai`).
3. Link and push to your remote:
   ```bash
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/nexora-ai.git
   git push -u origin main
   ```
4. On GitHub, navigate to **Settings** > **Pages**.
5. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
6. Your world-class AI website will be live in seconds at `https://YOUR_USERNAME.github.io/nexora-ai/`!
